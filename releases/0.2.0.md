# 0.2.0

- Enterprise-scope account management using SDK 5.5.0 and protocol 2.4.
- Plugin-declared Google identity, progressive scopes, channel pagination, native management labels
  and business permission groups. No provider-specific host UI or direct runtime HTTP route.
- Immutable UserInfo subject and optional name use `openid profile`; email is not requested.
- Development privacy/terms notices document consent, Brand Account limits and deployment requirements.

Preview only: no production OAuth verification, real-Google acceptance, publication or deployment is
claimed. Complete provider-data deletion and lifecycle enforcement remain production release gates.
