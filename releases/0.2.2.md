# 0.2.2

The reviewed video upload mapping now binds response ownership through `/snippet/channelId`.
Brokers must validate that field against the approved channel before releasing upload results.
SDK 5.5.0, protocol minimum 2.4, OAuth scopes, input/metadata schemas, action approvals and runtime
authority are unchanged. The runtime still rejects direct provider execution.

This is a new immutable package declaration, not a change to approved 0.2.1 records. Publishing,
installation, service package approval, matching consent, execution policy and business/agent grants
remain separate adoption steps. Synthetic tests do not establish a real upload, provider processing
or final visibility. Mismatched/uncertain outcomes must be reconciled without automatic replacement.
